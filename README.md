# ConvertFiles — ห้องแปลงไฟล์

เว็บภาษาไทยสำหรับแปลงรูปภาพและจัดการ PDF ผ่านเบราว์เซอร์ การแปลงทั่วไปทำในเครื่องผู้ใช้ ไม่อัปโหลดเอกสารไปยังเซิร์ฟเวอร์ แต่ต้องใช้อินเทอร์เน็ตเพื่อโหลดไลบรารีและฟอนต์

## ทำอะไรได้บ้าง

- **รูปภาพ:** แปลงเป็น JPG / PNG / WebP, บีบอัดภาพ และรวมหลายภาพเป็น PDF
- **แปลง PDF:** เป็น JPG, PNG, Word, PowerPoint หรือ Excel
- **จัดการ PDF:** ใส่รหัสผ่าน ปลดล็อกเมื่อรู้รหัสผ่าน และแปลภาษาเมื่อมีการเชื่อมต่อ Claude ที่รองรับ

## วิธีใช้

1. เลือกเครื่องมือ แล้วเลือกไฟล์หรือลากไฟล์มาวาง
2. ตั้งค่า เช่น คุณภาพ ช่วงหน้า หรือรหัสผ่าน
3. กดเริ่ม แล้วบันทึกผลลัพธ์ทีละไฟล์หรือรวมเป็น ZIP

ตัวอย่าง: เลือก **รูปภาพเป็น PDF** → เพิ่มรูป → เรียงลำดับด้วย ▲ / ▼ → กด **สร้าง PDF** → **บันทึก**

## ข้อจำกัด

- ไฟล์ Office อาจจัดหน้าไม่ตรงต้นฉบับ และยังไม่มี OCR สำหรับอ่านข้อความจากภาพสแกน
- การใส่รหัสผ่านและปลดล็อก PDF สร้างไฟล์ใหม่จากภาพแต่ละหน้า จึงเลือกหรือค้นหาข้อความเดิมไม่ได้
- การบีบอัดอาจไม่ทำให้ไฟล์เล็กลง และ PNG ระดับกลาง/ต่ำในเครื่องมือบีบอัดจะลดความละเอียด
- **การแปล PDF ยังใช้ไม่ได้บนเว็บทั่วไปหรือ Vercel** ต้องมี `window.claude.use('sample')` ที่รองรับ โดยจะส่งข้อความให้ Claude และจัดหน้าเอกสารใหม่

## รันในเครื่อง

ใช้ **Node.js 22 ขึ้นไป** เปิด Terminal ในโฟลเดอร์ที่มี `package.json` แล้วรันได้เลย ไม่ต้อง `npm install`

```sh
npm run dev
```

เปิด [http://localhost:3000](http://localhost:3000) ผ่านเซิร์ฟเวอร์นี้ แทนการเปิด `index.html` โดยตรง หาก PowerShell บล็อกคำสั่ง ให้ใช้ `npm.cmd` แทน `npm`

สร้างไฟล์เผยแพร่และดูตัวอย่าง:

```sh
npm run build
npm run preview
```

ไฟล์พร้อมเผยแพร่อยู่ใน `dist/` หยุด `dev` ก่อนเปิด `preview` เพราะใช้พอร์ต 3000 เหมือนกัน สำหรับ Vercel มีค่า build และ output ใน `vercel.json` แล้ว

## โครงสร้างหลัก

- `public/` — หน้าเว็บ HTML, CSS และ JavaScript
- `public/assets/js/tools/` — เครื่องมือแปลงไฟล์ทั้ง 11 รายการ
- `scripts/` — สคริปต์รันเว็บ สร้างไฟล์ และเรียกทดสอบ
- `tests/` — ชุดทดสอบในเบราว์เซอร์

ตรวจสอบด้วย `npm run build`, `npm run test:http`, `npm run test:images` และ `npm run test:system` โดยชุดทดสอบภาพและระบบต้องมี Chrome หรือ Edge ผลอยู่ใน `test-results/` และสรุปด้วย `npm run test:summary` การแปลใช้ตัวแปลจำลอง ส่วนไฟล์ Office ตรวจโครงสร้างไฟล์
